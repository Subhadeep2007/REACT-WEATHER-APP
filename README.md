# 🌦️ React Weather App

A modern and responsive **Weather Application** built with **React.js** that allows users to search for cities and view real-time weather information.

🔴 **Live Demo:**  
https://react-weather-app-pink-tau.vercel.app

📂 **GitHub Repository:**  
https://github.com/Subhadeep2007/REACT-WEATHER-APP

---

## 🚀 Features

- 🌍 Search weather by city
- 🌡️ Real-time temperature information
- 💧 Humidity information
- 💨 Wind speed and direction
- ☁️ Weather condition display
- 📍 Location-based weather support
- 🗺️ Map / location information
- 📱 Fully responsive design
- ⚡ Fast and smooth React UI
- 🔄 Dynamic weather data using API
- ⏳ Loading state while fetching data
- ❌ Error handling for invalid locations
- 🎨 Modern and clean UI

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Subhadeep2007/REACT-WEATHER-APP.git
```

### 2. Go to the project directory

```bash
cd REACT-WEATHER-APP
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create environment file

Create a `.env` file in the root directory:

```env
VITE_OPENWEATHER_API_KEY=your_openweather_api_key
```

> ⚠️ Never upload your API key directly to GitHub.

### 5. Start the development server

```bash
npm run dev
```

The application will run on:

```text
http://localhost:5173
```

---

## 🔑 API Setup

This project uses the **OpenWeather API** to fetch weather data.

You can create your own API key from:

https://openweathermap.org/api

After getting the API key, add it to your `.env` file:

```env
VITE_OPENWEATHER_API_KEY=YOUR_API_KEY
```
